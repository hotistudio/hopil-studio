# 호필 스튜디오

`index.html`이 앱의 시작 화면입니다. 화면 스타일은 `styles/`, 기능별 원본 코드는 `src/app/`에 있습니다. `scripts/app.js`는 원본 코드를 기존 실행 순서대로 합친 브라우저용 파일입니다.

기능 코드를 수정한 뒤 `node build-app.cjs`를 실행해 `scripts/app.js`를 갱신하세요. `node tests/safety.cjs`, `node tests/typewriter.cjs`, `node tests/editor.cjs`, `node tests/stats.cjs`, `node tests/reference.cjs`, `node tests/reader-style.cjs`로 저장·복구·가져오기와 집필 편집기·통계·참고 패널·화면 양식 검사를 실행할 수 있습니다.

**시각화 → 서사 타임라인**은 회차에 연결된 플롯 장면·심리 변화·복선의 첫 등장/언급/회수를 함께 보여줍니다. 항목을 누르면 원본 기록을 편집할 수 있고, 회차에 연결되지 않은 기록은 화면 아래에 모입니다. 관련 회귀 검사는 `node tests/narrative-timeline.cjs`와 `node tests/family-tree.cjs`로 실행합니다.

**플롯 구성 → 전체 흐름**에서는 같은 화의 장면을 ↑·↓ 버튼으로 정렬할 수 있습니다. 순서는 아크가 달라도 회차별로 저장되며 서사 타임라인의 플롯 칸에도 그대로 표시됩니다.

집필 편집기와 집중 모드의 **⌖ 타자기 스크롤** 버튼을 누르면 입력 중인 줄을 화면의 중간 부근에 유지합니다. 설정은 이 브라우저에 기억됩니다.

집필 편집기의 **⋯ 도구 → 화면 양식** 또는 집중 모드의 **화면 양식**에서 기본 집필기, 카카오페이지풍, 리디풍, 네이버 시리즈풍, 짙은 녹색을 고를 수 있습니다. 선택은 이 브라우저에 기억됩니다. 원고 내용은 바뀌지 않습니다. **내보내기 → HWPX**는 선택한 양식의 글꼴 종류·글자 크기·행간·본문색·용지색과 여백을 한글 문서에 반영합니다. 화면의 바깥 배경이나 정확한 픽셀 폭은 종이 문서에 그대로 옮길 수 없습니다. 플랫폼별 스타일은 독서 분위기를 참고한 예시이며 실제 앱 화면이나 제출 규격과 동일하지 않습니다.

HWPX는 한컴오피스 한글에서 편집할 수 있습니다. `.hwp`가 필요하면 한글에서 HWPX를 연 뒤 **다른 이름으로 저장 → 한글 문서(*.hwp)**를 선택하세요. HWPX 템플릿의 출처와 라이선스는 `assets/HWPX-TEMPLATE-LICENSE.txt`에 있습니다.

데스크탑과 태블릿에서는 집필기와 참고 패널 사이의 경계를 드래그해 너비를 조절할 수 있습니다. 태블릿에서 참고 패널을 열면 회차 목록이 접혀 본문 공간을 확보합니다. 경계에 키보드 초점을 두고 좌우 화살표로도 조절할 수 있습니다.

참고 패널의 개요와 관계도는 집필 화면을 떠나지 않고 수정할 수 있습니다. 집중 모드의 참고 패널도 일반 패널과 입력 대상을 구분해 처리합니다. 모바일에서는 가로로 밀 때만 참고 패널이 닫히므로 세로로 자료를 스크롤할 수 있습니다.

설치와 오프라인 기능은 HTTPS 또는 `localhost`에서 제공할 때 동작합니다. 원고는 현재 브라우저의 저장공간에 자동 저장되므로, 작품 또는 전체 JSON 백업을 별도로 보관하세요.

집필 통계는 기기의 현지 날짜를 사용합니다. 직접 입력해 원고가 늘어난 글자만 집계하며 붙여넣기와 실행 취소·다시 실행은 제외합니다. 새 JSON 백업에는 해당 작품의 집필량과 타이핑 시간 통계가 포함됩니다. 예전 백업은 계속 불러올 수 있지만, 파일에 없던 통계는 복원할 수 없습니다.

`/hopil-studio/`는 예전 `/wnstudio/`와 별도의 저장 키를 사용합니다. 새 버전을 처음 열 때 기존 브라우저의 원고를 한 번 복사하며, 이후 두 앱의 수정 내용은 서로 반영되지 않습니다. 다른 기기의 원고는 JSON 백업 파일을 각 기기에서 불러와야 합니다.
