# 호필 스튜디오

`index.html`이 앱의 시작 화면입니다. 화면 스타일은 `styles/`, 기능별 원본 코드는 `src/app/`에 있습니다. `scripts/app.js`는 원본 코드를 기존 실행 순서대로 합친 브라우저용 파일입니다.

기능 코드를 수정한 뒤 `node build-app.cjs`를 실행해 `scripts/app.js`를 갱신하세요. `node tests/safety.cjs`와 `node tests/typewriter.cjs`로 저장·복구·가져오기와 타자기 스크롤 검사를 실행할 수 있습니다.

집필 편집기와 집중 모드의 **⌖ 타자기 스크롤** 버튼을 누르면 입력 중인 줄을 화면의 중간 부근에 유지합니다. 설정은 이 브라우저에 기억됩니다.

설치와 오프라인 기능은 HTTPS 또는 `localhost`에서 제공할 때 동작합니다. 원고는 현재 브라우저의 저장공간에 자동 저장되므로, 작품 또는 전체 JSON 백업을 별도로 보관하세요.

`/hopil-studio/`는 예전 `/wnstudio/`와 별도의 저장 키를 사용합니다. 새 버전을 처음 열 때 기존 브라우저의 원고를 한 번 복사하며, 이후 두 앱의 수정 내용은 서로 반영되지 않습니다. 다른 기기의 원고는 JSON 백업 파일을 각 기기에서 불러와야 합니다.
